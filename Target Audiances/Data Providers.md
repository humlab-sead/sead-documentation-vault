# ==🟠Data Providers==
## Target Group
Researchers, institutions, projects, and data managers preparing datasets for submission to SEAD.
## Purpose
Help contributors understand requirements, prepare datasets correctly, and complete the submission and ingestion process efficiently.
## Typical Questions
- What data formats are accepted?
- What metadata are required?
- How should records be structured and documented?
- What quality-control requirements must be met?
- How does the submission workflow operate?
## Document Types
- Submission guides
- Data-format specifications
- Metadata standards
- Templates
- Contributor checklists
- Ingestion workflows
- Data-quality guidance
## Expected Technical Level
Subject-matter expertise expected; limited knowledge of SEAD internals assumed.
## Success Criteria
Providers can prepare and submit datasets with minimal assistance and few ingestion issues.
## Out of Scope
Database administration, server operations, and software development documentation.
