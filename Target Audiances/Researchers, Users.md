# ==🟢Researchers / Users==
# Target group
- These are researchers, students, or anyone retrieving data from SEAD with the goal of interpreting and/or using the data, no matter if they use the browser, or an API to access the data.
- The documentation for this group is aimed at helping them understand the database structure and content sufficiently well enough to answer their research questions.
# Goals for documentation for this group
- Enabling research and analysis of the data
- Ensuring proper citation of the data
# Document types
- Scientific papers describing SEAD infrastructure
- Scientific papers describing any aspect of SEAD data
- User Guides
- SEAD's in-built tutorial
- Data Coverage summaries
- Limitation/Constraints on the data (possibility dataset specific)
- API technical info needed to access the data that way (also important for [[Audience, Technical]])
- Licencing info
- Version info (especially important for citing the database--Arbodat data ought to cite Arbodat first, not SEAD)

# ==🟢Researchers / Users==
## Target Group
Researchers, students, educators, and other users seeking to discover, access, analyse, and interpret SEAD data.
## Purpose
Enable users to find relevant data, understand its meaning, and use it correctly in research and teaching.
## Typical Questions
- What data are available?
- How can I search and retrieve data?
- How should specific tables or fields be interpreted?
- What are the limitations of the data?
- How should data be cited?
## Document Types
- User guides
- Search tutorials
- Data dictionaries
- Research workflows
- Case studies
- Citation guidance
- Frequently asked questions
## Expected Technical Level
Moderate familiarity with archaeological and palaeoecological data; limited knowledge of system architecture assumed.
## Success Criteria
Users can locate, understand, retrieve, and correctly interpret SEAD data independently.
## Out of Scope
Server administration, deployment, and source-code documentation.
