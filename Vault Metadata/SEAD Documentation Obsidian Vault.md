This Obsidian Vault was created 2026-11-17 as a way to begin to organise SEAD's various documentation files so that we can determine what additional documentation, if any will be needed.
# Organisation Guideline (Target Audience)
All Documentation will be tagged with respect to its target audience. We initially defined six target audiance groups:
1. Data Manegment/Polity/Risk Assessment
2. Data Providers
3. Funding Bodies/Outreach
4. Researchers/Users
5. Systems/Maintaince/Operations
6. Technical
There being six groups, they have each been assigned a colour from the rainbow. These colours will be used throughout the vault.
