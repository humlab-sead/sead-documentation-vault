# Organisation Guideline (Target Audience)
All Documentation will be tagged with respect to its target audience. We initially defined six target audiance groups:
1. [[data_management]]: <span style="color:rgb(228, 3, 3)">Data Management / Policy / Risk Assessment</span>
2. [[data_providers]] <span style="color:rgb(255, 140, 0)">Data Providers</span>
3. [[funding_bodies]] <span style="color:rgb(255, 237, 0)">Funding Bodies / Community Outreach</span>
4. [[systems_maintenance]] <span style="color:rgb(0, 128, 38)">Systems / Maintenance / Operations</span>
5. [[technical]] <span style="color:rgb(0, 77, 255)">Technical</span>
6. [[users]] <span style="color:rgb(117, 7, 135)">Researchers / Users</span>
